# Marca Joga Placa

Esta pasta recebe os arquivos oficiais da identidade visual legada.

## Arquivo principal esperado

- `joga-placa-logo.png` — logo/placa oficial do Joga Placa, preferencialmente com fundo transparente e boa resolução.

O caminho público no Next.js será:

`/brand/joga-placa-logo.png`

Coloque o arquivo com esse nome exato. Não é necessário alterar o código para apontar para outro nome. Se o logo oficial estiver disponível em SVG, avise antes de trocar a extensão para manter o apontamento consistente.

A imagem de referência enviada na conversa serve como guia visual, mas não foi adicionada como se fosse o arquivo oficial original.
